# 📩 Spam Detection System

## 🧠 Overview
This project is a Machine Learning-based Spam Detection System that classifies messages as **Spam or Not Spam (Ham)** using Natural Language Processing techniques.

---

## 🚀 Features
- Detects spam messages using ML model
- Simple and clean Flask web interface
- Fast prediction using trained model
- Easy to deploy on cloud (Render)

---

## 🛠️ Tech Stack
- Python 🐍
- Flask 🌐
- Scikit-learn 🤖
- Pandas 📊
- NumPy 🔢
- NLP (TF-IDF / CountVectorizer)
